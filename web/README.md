# Treningsdagbok – nettsiden

Vite + React + TypeScript. Se [README](../README.md) i prosjektroten for hvordan siden
startes og dataene oppdateres, og [CLAUDE.md](../CLAUDE.md) for oppbyggingen.

```
npm install
npm run dev     # http://localhost:5180, med assistenten bak «Spør»
npm test
npm run lint    # advarsler regnes som feil
npm run build   # typesjekker også testfilene
```
